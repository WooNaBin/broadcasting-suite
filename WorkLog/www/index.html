    기록 규칙 설정

    방송실 특이사항 메모는 날짜와 무관하게 NAS에 저장됩니다.

    플레이스홀더: {schedule_title} {place} {place_label} {start_time} {sermon_speaker} {accessory_info} {preparation_note} {date}

    기본 일정 기록 시 선택한 스케줄 필드가 값 조건을 만족하면 기록·템플릿이 반영됩니다.

    조건 필드: schedule_title / accessory_info / preparation_note. 값 예: 집회or지원(하나라도), 집회and지원(모두).

    제목 규칙은 위에서부터 검사하며, 스케줄마다 처음 맞는 규칙만 적용합니다. ↑↓로 우선순위를 바꿉니다.

    업무 템플릿 버튼을 직접 켤 때 일지에 추가될 기본 텍스트입니다. 기록 위치(A/B)를 고를 수 있으며 기본은 A입니다.
