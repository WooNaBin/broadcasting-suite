# WorkLog — Agent 안내

작업을 시작하기 전에 **반드시** [`.cursor/agent-settings.md`](.cursor/agent-settings.md) 를 읽고, 그 값과 [`.cursor/rules/`](.cursor/rules/) 를 따른다.

고칠 것·할 일·메모: [`docs/TODO.md`](docs/TODO.md). 「할 일 해줘」라고 하면 그 파일 기준으로 처리한다.

사용자가 설정을 바꿨으면 코드/규칙보다 **그 파일의 현재 값**을 우선한다.
규칙 문구를 고치고 싶으면 `.cursor/rules/*.mdc` 를 수정한다.
