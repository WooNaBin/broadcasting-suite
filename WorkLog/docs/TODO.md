## 쓰는 방법

- 새 항목: `- [ ]` 아래에 한 줄로 적기. 필요하면 들여쓴 메모 추가.
- 우선순위가 있으면 `[높음]` / `[보통]` / `[낮음]` 표시.
- 끝나면 `- [x]` 로 바꾸거나 **완료** 섹션으로 옮기기.
- 에이전트가 처리한 항목은 체크하고, 짧은 처리 메모를 남긴다.
