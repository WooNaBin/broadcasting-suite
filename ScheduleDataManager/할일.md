# 할 일 / 고칠 일 메모

여기에 고칠 점·할 일을 적어 두세요.  
채팅에서 **「할일 해줘」**, **「그거 해줘」**, **「메모 해줘」** 라고 하면 에이전트가 이 파일을 읽고 처리합니다.

## 쓰는 방법

- `- [ ]` : 아직 안 함
- `- [x]` : 끝남 (에이전트가 처리한 뒤 체크하거나, 직접 체크)
- 한 줄에 하나만. 짧게 적어도 됩니다.
- 급한 건 위에, 나중에 할 건 아래에.
