UI 데모 허브 빌드·NAS 없이 현재 소스 UI만 확인

방송실 프로그램 UI 데모

각 링크는 해당 앱 소스의 ?demo=1 또는 전용 데모 페이지입니다. API는 브라우저 메모리 목(mock)으로 응답하므로 NAS·브리지가 없어도 됩니다.

브리지 허브 앱 카드·상태 배지 레이아웃 (정적 데모) 스케줄 (SDM) 로그인 건너뛰기 · 샘플 일정으로 셸 UI 작업일지 (WorkLog) 상태창 → 프로필/PIN → 메인 에디터 파일체크 (FileChecker) 샘플 스케줄 목록·필터·설정 모달 CtrlOne 기존 레이아웃 데모 (가상 HyperDeck) ScheduleReader 샘플 표·추출 결과 UI (서버 API 없음)
실행
저장소 루트에서 demos\Open-UiDemos.bat (Windows) 또는 demos/Open-UiDemos.command / demos/Open-UiDemos.sh (Mac)를 실행하세요. 정적 서버(http://127.0.0.1:17990)가 뜨고 이 허브가 열립니다. Windows는 PowerShell 내장 서버, Mac은 Python3를 사용합니다. file:// 로 직접 열면 ES 모듈·상대 경로가 깨질 수 있습니다.
